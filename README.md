# AULA360

Sistema Inteligente de Gestión y Evaluación Educativa.
"Planea. Enseña. Evalúa. Mejora."

Ver `PROGRESO_AULA360.md` para el estado real del proyecto, fase por fase.

## Empezar

1. `cp .env.local.example .env.local` y completa tus credenciales de Supabase.
2. Corre `supabase/migraciones/001_esquema_inicial.sql` en tu proyecto Supabase.
3. Crea tu primer usuario superadmin (ver PROGRESO_AULA360.md).
4. `npm install`
5. `npm run dev`
